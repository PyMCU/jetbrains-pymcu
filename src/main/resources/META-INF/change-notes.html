0.1.0

First public release.

  • Porting assistant: pymcu lint findings as editor annotations and a navigable list in the PyMCU tool window.
  • Project configuration dialog fed by pymcu boards --json, covering every board the installed backends support; writes board / target and the [tool.pymcu.flash] table while preserving comments and formatting.
  • Run configurations for build, flash, clean, sync and stubs, with --verbose, --explain and --debug options and clickable compiler diagnostics.
  • IDE stubs generated by pymcu stubs instead of by the plugin, so signatures stay in step with the installed stdlib.
  • Serial-port picker on flash; status bar target indicator that opens the configuration dialog.
  • Reads the current [tool.pymcu] schema — target, board, the flash and toolchain tables — through a real TOML reader.
