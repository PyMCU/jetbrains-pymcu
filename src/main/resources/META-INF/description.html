Official PyCharm support for PyMCU — a compiler that turns a statically-typed subset of Python into bare-metal firmware for AVR, RP2040 / RP2350, PIC and RISC-V microcontrollers. No runtime, no interpreter, no VM.

  • Build, flash and clean as run configurations, with pymcuc diagnostics turned into clickable file:line:col links in the console.
  • Porting assistant — pymcu lint findings appear as editor annotations as you type or save, each with a concrete rewrite. Paste MicroPython code and follow the squiggles until it compiles.
  • Resolution and completion for pymcu.*, the MicroPython / CircuitPython compat layers (machine, board, digitalio, …) and the generated board module for your target.
  • Project configuration dialog — board, clock, compat stdlib, programmer, serial port and AVR fuses, written back to [tool.pymcu] without disturbing your formatting. The board list comes from the installed CLI, so it always matches your backends.
  • Status bar target indicator, serial-port picker on flash, and a New Project wizard that scaffolds a working blink for the board you pick.

Requires the PyMCU CLI: pipx install pymcu-compiler, or add pymcu-compiler to your project with uv.
